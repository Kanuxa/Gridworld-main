# Obsolete intra-episode dynamics prototype

These small smoke artifacts were produced by a rejected prototype that changed
the environment during an episode.  `sensory_grid_env_v5.py` has been restored
to its original stationary behavior, so these files are retained only for
auditability and must not be used for training, checkpoint selection, or
reported results.

Current V12 experiments belong under `experiments/adaptive_v12/` and use
different stationary reset worlds selected by seed and profile family.
